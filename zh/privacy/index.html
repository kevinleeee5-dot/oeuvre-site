隐私说明

我们收集哪些信息、为什么需要，以及谁会参与处理。这里把事情说清楚。

最后更新：2026 年 11 月 5 日

我们是谁

Oeuvre 是 BNB Management Consulting Ltd 的经营名称，位于新西兰奥克兰。

我们负责本网站及通过网站收集的信息。

如有疑问，欢迎写信至 info@bnbmanagement.co.nz。

访问统计

我们使用 Microsoft Clarity 了解网站的使用情况，包括访问的页面、停留时间、滚动与点击、设备及浏览器类型，以及大致所在地区。

这些信息帮助我们发现不够直观的设计、失效的功能，以及需要改进的体验。

Clarity 使用 Cookie 识别重复访问，并可能记录页面的交互过程。在这些记录中，对话框里的输入内容和对话文字会被遮挡。

相关数据由 Microsoft 按照其隐私政策处理，并依其保留规则存储。

首页的人像

首页的人像由预先制作的视频呈现，不会调用你的摄像头。

如果你选择与它对话，输入的文字或语音转写内容会发送至 Anthropic，由 Claude 生成回复。回复随后交由 ElevenLabs 转换为语音。

为了了解访客的需求并持续改进网站，我们会在服务器上保留对话文字，最长 90 天。

保存的对话不会附带你的 IP 地址，邮箱和电话号码会自动遮盖。我们也会使用 Claude 整理前一天的对话，生成简短摘要并通过邮件发送给网站团队。

请不要在对话中提供你不希望我们看到的私人或敏感信息。

为防止滥用，我们会记录消息数量和服务费用，并以哈希形式短暂保存 IP 地址，约一小时后清除。

语音识别由浏览器提供，仅在你按住空格键或主动点击麦克风时启用。部分浏览器可能将录音发送给其服务商进行转写。

其他服务

网站由 Hostinger 托管。服务器可能保留标准访问日志，包括 IP 地址、访问时间和请求的页面。

网站字体通过 Google Fonts 加载。在此过程中，Google 可能收到你的 IP 地址。

我们也会在你的设备上保存少量网站偏好，例如声音开关和是否已观看开场动画。这些设置只保存在你的浏览器中。

信息会去哪里

我们使用的部分服务商，包括 Microsoft、Anthropic、ElevenLabs、Google 和 Hostinger，可能在新西兰境外处理数据，包括美国。

这些服务商按照各自的隐私政策处理相关信息。我们会根据服务需要选择第三方，并关注其数据保护方式。

邮件

如果你主动联系我们，我们会使用你提供的信息回复邮件、讨论合作或处理相关请求。

这些通信会在业务处理及合理存档所需的期限内保留，不用于无关目的。

你的权利

根据新西兰《2020 年隐私法》（Privacy Act 2020），你有权要求查阅我们持有的关于你的个人信息，并请求更正。

请通过 info@bnbmanagement.co.nz 联系我们。

如果你对我们的处理方式不满意，也可以联系新西兰隐私专员办公室（privacy.org.nz）。

更新

当我们收集或处理信息的方式发生变化时，会相应更新本页。

页面顶部的日期代表最新版本。
