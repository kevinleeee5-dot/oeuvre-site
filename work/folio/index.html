Work / 03

Folio

A quiet reading app with a daily edition you can read or listen to.

SectorMedia / reading
RoleApp · Editorial · Audio
Year2026

The brief

Reading apps shout. Folio had to feel like a well-made paper: a daily edition with a beginning and an end, read or narrated, then put down.

What we did

  1. Designed a daily edition with a clear start and finish.
  2. Set the type for long reading, in light and dark.
  3. Chose a calm, natural narration voice and built background listening with lock-screen controls.
  4. Kept the whole pipeline small enough to run every day.

Where it is now

In private testing on iPhone.
