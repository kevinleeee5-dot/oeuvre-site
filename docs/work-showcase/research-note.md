# 高级案例页是怎样的 — 研究笔记（2026-11-01）

看过的页面（截图在 scratchpad/ref，未入库）：Rejouice × Oura Ring、Basement × Baseten、Studio Freight × Applause、Locomotive × Baillat Studio、Hello Monday × Bearaby、Lusion × Of The Oak、heirest.com、domani.be；加上 Active Theory / Resn / Immersive Garden / Obys / Exo Ape 的常规做法（预加载与平滑滚动让无头截图拿不到深层内容，按已知的作品页结构补充）。

## 让人觉得"高级"的八个共同点

1. **节奏：一屏一件事。** 首屏只有一张满屏图和一句话（Rejouice：整屏戒指特写 + "The Smart Ring."）。第二屏只有一段定位文字。每一屏只回答一个问题，滚动是翻页，不是往下看列表。我们 v2 的问题正是一屏里塞了三件事。
2. **尺度对比。** 标题 160–240px，正文 15–17px，图注 11–13px 全大写加字距；中间几乎没有中号字。大字只用一次（标题或一句定位），其余都小。数字可以很大（"4 models · 35 s"）。
3. **图片不带设备框，而是"裁切 + 出血 + 叠压"。** Rejouice 把手与戒指裁成竖长特写、再在下一屏换成横向出血；Studio Freight 把海报、手机、名片以不同比例错落叠放；Basement 用整屏双栏图。设备（iPad / iPhone / Mac）要么只露一角、要么成组错位，带柔和投影，绝不整齐排一行。
4. **不对称网格和大量留白。** 7/5、8/4 的分栏，图片越过栏线；文字块窄（28–34 字），放在图的对角。Locomotive 的奖项表、Hello Monday 的 logo 说明都是"小字 + 大空"。
5. **图片处理统一。** 同一页内图片有一致的调子（Rejouice 米色底 + 深蓝；Studio Freight 黑白 + 一个蓝）。我们的黑白世界本身就是优势：灰度 + 微对比，再加一种"手法"（半调网点）贯穿即可；可加遮罩（圆、超大圆角、斜切）和投影作第二层手法。
6. **动效是"滚动驱动"的层次，而非装饰。** 首图随滚动缩放 1.08→1；文字以行为单位升起；并排两层以不同速度位移（视差 0.6×/1×）；粘性媒体（sticky）配随滚动切换的小标；视频静音循环、入视口才播。Lusion 把整个项目做成一个随滚动推进的 3D 场景，但原则相同：滚动 = 时间轴。
7. **叙事节拍：钩子 → 细节 → 结果。** 一句定位（为什么）、一个关键想法（怎么做）、两三个宏观细节（放大看）、一行数字（结果）、下一个项目（交接）。中间穿插不超过三段正文。
8. **字体系统只有一套。** 一款字体、三个字重、固定的字距规则（大字负字距、小字正字距），图注永远同一位置（图下左对齐）。

## 对 Oeuvre 案例页的直接转化

- 页面结构固定为：满屏首图（标题压图）→ 一句想法（整屏黑底大字）→ 场景 A（设备 / 产品的再构图）→ 故事行 A（大裁切 + 短文）→ 场景 B → 故事行 B（反向）→ 数字行 → 下一个项目。
- 每个项目一个"再构图"主意：Bei`Care = iPad 斜浮 + 一张放大的图表卡叠在角上；Folio = 五张屏幕扇形展开 + "surprise" 查词卡放大成整屏；ACE = 卷盘放大到出血并旋转 + "18°/s" 大字；MUZI = 花盆错落叠放在浅底上 + 麦饭石圆形遮罩；Stillora = 胶片条（带齿孔）横向溢出 + 3D 乐器放大。
- 动效按项目各做一页分镜，统一节奏：首图 1.08→1 缩放 1.2 s；标题逐行升起（每行 60 ms）；一句想法按三组词淡入；场景内两层视差；数字 1.2 s 计数；下一个项目悬停时底图从 40% 到 100%。
